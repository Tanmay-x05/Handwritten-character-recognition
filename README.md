Neural Character Recognition System (Digits & Letters)
Developed an end-to-end handwritten character recognition system for both digits and alphabetic characters, using MNIST and EMNIST Letters datasets. The project involved image preprocessing, normalization, and character segmentation, followed by a comparative evaluation of classical machine learning models (KNN, Random Forest) and a deep learning–based Convolutional Neural Network (CNN) implemented using TensorFlow/Keras.
Designed the CNN to automatically learn spatial features from raw images, while traditional models relied on handcrafted feature representations. Conducted systematic performance evaluation using accuracy, precision, recall, and weighted F1-score, demonstrating that the CNN significantly outperformed classical approaches, achieving high accuracy and robustness. The system was built with TensorFlow, NumPy, and OpenCV, and structured to support experimentation, extensibility, and learning in computer vision and machine learning workflows.
